Cloudflare setup

Protect your agent

1. Create the token Once, in Cloudflare. Takes about two minutes.

Never paste this token into a chat, issue or message, including to an agent. Paste it only into this page. Cloudflare shows it once; if you lose it, roll it from API Tokens.

  1. Sign in to the Cloudflare dashboard on the account that hosts your agent.
  2. Open Manage Account → API Tokens. If setup later says this token is not accepted, use My Profile → API Tokens instead; the steps are the same.
    Screenshot pending.
  3. Click Create Token, then Create Custom Token.
  4. Name it taskfast-access-setup.
  5. Add two permissions, both in the Account group:
    • Access: Apps and Policies → Edit (some dashboards say Write)
    • Access: Organizations, Identity Providers, and Groups → Read
    Add nothing else.
    Screenshot pending.
  6. Account Resources: Include → your one account, not all accounts.
  7. Client IP Address Filtering is optional. Set it to your home address if that address never changes.
  8. TTL: pick an end date. Seven days is enough for setup; delete the token afterwards.
  9. Click Continue to summary, check it lists only those two permissions on one account, then Create Token and copy it.

2. Fill in three details Your token stays on this computer.

What setup will do

    • DoneYour agent is behind Access.

    Open your Worker URL, sign in with the code Cloudflare emails you, then open the console link setup printed. You can close this page; setup has stopped.

    To see who is allowed in, open Zero Trust → Access → Applications → the app named after your Worker → Policies. To change the address, run setup again with the new email and confirm the change.
